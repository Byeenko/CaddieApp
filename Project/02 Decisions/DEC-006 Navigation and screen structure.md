# DEC-006: Navigation and screen structure

## Decision
Five tabs: **Home · Library · Search · Saved · Caddie**.

- Each tab keeps its own back history, like a native iPhone app. Tapping the tab you're already on jumps back to its first screen.
- Library flow: Library → Category → Topic (subtopics shown as sections) → Lesson.
- Lessons show where they sit in the library, key points, callouts, and "Up next" and "Related" at the bottom.
- Design: system fonts, New York serif for reading, fairway-green accent, automatic dark mode.

## Why
Matches how iPhone apps behave, so it feels native. Five tabs is the iPhone maximum before a "More" tab appears.

## Revisit if
A sixth main area is needed. Settings, for example, would likely live inside Home or Caddie rather than get its own tab.
