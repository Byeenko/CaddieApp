# DEC-007: Content writing order

## Context
Claude asked which part of the library to fill first. You said you had no preference.

## Decision
Write in this order:
1. Swing fundamentals ✅
2. Short game ✅
3. Putting
4. Course management and club selection
5. Remaining uneven lies, then everything else

## Lesson standard
Key points first, then the explanation, a common mistake, a drill, and a tour example where it adds something. Australian spelling, yards, right-handed.
